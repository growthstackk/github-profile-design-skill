# GitHub Profile Designer Skill: Autonomous Agent Protocol

This skill equips any AI Code Agent (Antigravity, Claude Code, Cursor, Copilot Workspace, Windsurf, Devin) with the complete methodology to transform an ordinary developer profile into an elite, company-grade Developer Technology Studio & AI Engineering profile.

## Phase 1: Developer Intake & Interactive Questionnaire
Before designing anything, present the structured questionnaire to the developer:
1. GitHub username and preferred display name.
2. Core engineering disciplines (Full-Stack, Mobile, Agentic AI, Cloud/DevOps).
3. Primary production tech stack.
4. Flagship repositories and projects to highlight.
5. Preferred visual personality (Obsidian Cyber Studio, Vercel Minimalist, Retro Terminal).
6. Public contact channels.

## Phase 2: Design Scouting & Reference Research
1. Research 15-20 benchmark developer and engineering studio profiles.
2. Synthesize layout patterns, uniform badge structures, and borderless dynamic metric widgets.

## Phase 3: Strategic Planning Documentation
Create 5 core markdown planning documents:
- RESEARCH-REPORT.md
- EXISTING-PROFILE-AUDIT.md
- BRAND-IDENTITY.md
- DESIGN-SYSTEM.md
- IMPLEMENTATION-ROADMAP.md

## Phase 4: Safe Authentication & Account Discovery
1. Direct the user to official browser login or CLI authentication.
2. Never request passwords, OTPs, or session tokens.
3. Verify public repositories and special profile repository status.

## Phase 5: Asset Generation & Production README Construction
1. Create responsive vector SVG hero banner with dark gradient aesthetic and domain pills.
2. Build production README with Executive Studio Matrix, Agentic AI Spotlight, Categorized Tech Ecosystem, Flagship Solutions, and Live Metrics.

## Phase 6: Diff Review, Approval & Deployment
1. Present full proposed diff to the user for explicit approval.
2. Commit files to `<username>/<username>`.
3. Update GitHub profile bio and company metadata.
4. Verify live rendering across desktop and mobile viewports.
