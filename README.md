## 🎯 Overview

This repository houses the formal specification and execution playbook for the **GitHub Profile Designer Skill**. It enables autonomous coding agents (**Antigravity, Claude Code, Cursor, Copilot Workspace, Windsurf, Devin**) to autonomously architect, draft, build, and deploy GitHub profile ecosystems.

See a production deployment designed and published using this skill at: **[github.com/growthstackk](https://github.com/growthstackk)**.

## 🚀 The 6-Phase Autonomous Agent Pipeline

```
[ Phase 1: Intake ] ──▶ [ Phase 2: Scout ] ──▶ [ Phase 3: Strategy ]
                                                      │
                                                      ▼
[ Phase 6: Publish ] ◀── [ Phase 5: Assets ] ◀── [ Phase 4: Discovery ]
```

### 1. Developer Intake & Questionnaire
Collects profile requirements interactively: target branding, engineering disciplines, tech stack, flagship projects, and visual aesthetics.

### 2. Design Scouting & Benchmark Research
Analyzes leading developer and tech studio profiles for typography, badge uniformity, dark mode compatibility, and live stat cards.

### 3. Strategic Planning & Architecture
Generates 5 foundational markdown artifacts:
- `RESEARCH-REPORT.md`
- `EXISTING-PROFILE-AUDIT.md`
- `BRAND-IDENTITY.md`
- `DESIGN-SYSTEM.md`
- `IMPLEMENTATION-ROADMAP.md`

### 4. Safe Authentication & Account Discovery
Safe discovery protocol directing developers to official browser or CLI authentication without exposing secrets or credentials.

### 5. Asset Generation & README Construction
Generates custom dark-mode SVG vector hero banners and builds responsive profile READMEs with:
- Executive Studio Matrix
- Agentic AI & Autonomous Systems architecture diagrams
- Categorized tech ecosystem badges
- Flagship solution showcase
- Borderless live contribution streaks and GitHub stats

### 6. Review, Diff Approval & Verified Deployment
Executes deployment to `<username>/<username>` and configures GitHub profile settings with visual verification.
